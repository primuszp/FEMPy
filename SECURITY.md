# Biztonsági és mérnöki felelősségi megjegyzés

A FEMPy oktatási és kutatási célú szoftver. Nem minősített, nem tanúsított
tervezőprogram. Biztonságkritikus döntést ne alapozz kizárólag az eredményeire;
használj független ellenőrzést, hálókonvergencia-vizsgálatot és a vonatkozó
szabványok szerinti mérnöki felülvizsgálatot.

Szoftverbiztonsági hibát ne nyilvános issue-ban közölj. A GitHub repository
Security felületén küldj privát jelentést.
